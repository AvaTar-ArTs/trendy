# choTaku Trendshift Launch Plan

## Core message

**choTaku is a provider-neutral storyworld compiler that turns canon, character identity, lore, relationships, events, scenes, visual layouts, and provenance into reproducible comic, manga, storyboard, cinematic, and multimodal artifact plans.**

## Why this project is discoverable

The strongest category intersections are:

- AI agent
- AI skills
- MCP
- AI workflow
- Workflow automation
- AI image generation
- AI video generation
- Creative tooling
- Story generation
- Comic generation
- Multimodal production
- Provenance and continuity

Use only the topics that the repository actually supports.

## Recommended release sequence

### Release 0.1.0 — Semantic kernel

- Storyworld schema
- Canon and entity models
- Scene contracts
- Validation
- Deterministic compilation
- Example fixture
- Provenance manifest

### Release 0.2.0 — Visual planning

- Layout contracts
- Panel and shot projections
- Character continuity anchors
- Storyboard export
- Visual layout examples

### Release 0.3.0 — Adapter boundary

- Provider-neutral adapter interface
- Image/video/audio generation hooks
- MCP inspection and compile contracts
- Dry-run execution
- Resumable checkpoints

## Announcement sequence

### Day 0

- Publish release
- Submit to Trendshift
- Publish GitHub Release
- Post the technical announcement

### Days 1–3

- Share the architecture diagram
- Publish the Crimson Curse example
- Invite users to try one fixture
- Respond to issues and questions

### Days 4–7

- Publish a technical walkthrough
- Demonstrate a layout or storyboard projection
- Merge a small documentation or fixture contribution
- Summarize feedback

### Weeks 2–4

- Release an improvement based on user feedback
- Add one external example
- Publish a comparison with ordinary prompt-only comic generators
- Continue documenting real usage

## Success criteria

Do not define success as a Trendshift rank alone.

Primary outcomes:

- Clean installs
- Repeat users
- Useful issues
- External examples
- Forks with modifications
- Contributions
- Stable releases
- Better story continuity and artifact reproducibility

Secondary outcomes:

- Trendshift repository profile
- Daily or weekly appearance
- GitHub Trending appearance
- External mentions
