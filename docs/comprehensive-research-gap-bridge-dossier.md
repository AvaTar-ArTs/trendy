# AvatarArts Comprehensive Research, Sources, and Gap-Bridge Dossier

Updated 2026-08-15. This dossier consolidates the research demands, source families, comparable systems, product references, AvatarArts evidence, and the capabilities available to bridge the identified gaps.

## 1. Research mandate

The recurring research request was broader than “find AI comic generators.” The actual mandate was to discover, compare, and operationalize systems across:

- comics, manga, graphic novels, storyboards, and picture books
- characters, identity, visual consistency, psychology, lore, and relationships
- storyworld graphs, timelines, scenes, beats, and cinematic projections
- multimodal generation across image, video, audio, music, and text
- AI agents, Agent Skills, MCP servers, tool registries, and memory systems
- asset intelligence, metadata, deduplication, provenance, and lineage
- local-first and provider-neutral creative infrastructure
- publishing, distribution, marketplaces, productization, and creator businesses
- trend intelligence across repositories, packages, models, products, skills, papers, media, and communities
- platform mechanics for GitHub, Trendshift, Hugging Face, Product Hunt, skills.sh, npm, PyPI, MCP directories, Reddit, Hacker News, X, LinkedIn, Dev.to, Gumroad, Fiverr, Obsidian, and websites

The desired output was:

```text
search demands
→ source registry
→ comprehension
→ capability comparison
→ gap analysis
→ proprietary architecture
→ implementation roadmap
→ launch and distribution system
```

## 2. Source-quality model

### Tier A — first-party evidence

Direct repositories, official documentation, official APIs, release notes, and the user’s authored systems.

Use for:

- actual implementation behavior
- licensing
- API capabilities
- package and installation rules
- repository metadata
- provenance
- current product features

### Tier B — academic and research evidence

Papers, benchmarks, surveys, and reproducible research.

Use for:

- representations
- evaluation methods
- interaction models
- technical limitations
- emerging research direction

### Tier C — platform signals

Trendshift, GitHub Trending, Hugging Face rankings, Product Hunt categories, package download analytics, skill directories, and MCP directories.

Use for:

- discovery
- momentum
- relative popularity
- distribution opportunities

Do not treat rankings as quality proof.

### Tier D — industry analysis

Vendor reports, launch analyses, technical blogs, and market studies.

Use for:

- strategic direction
- market framing
- adoption patterns
- hypotheses

Mark vendor incentives and methodology limits.

### Tier E — community and secondary evidence

Reddit discussions, Dev.to posts, social posts, community lists, and tutorials.

Use for:

- practical friction
- user language
- implementation anecdotes
- discovery leads

Do not use alone for critical factual claims.

## 5. Requests and search demands translated into system requirements

### “Find similar creative systems”

Requirement: maintain an adjacent-system registry with capability, boundary, license, maturity, evidence, and adaptation notes.

### “Search beyond GitHub and Hugging Face”

Requirement: scan directories, registries, products, papers, marketplaces, social communities, and package ecosystems.

### “Find comic, manga, graphic-novel, storyboard, and picture-book creators”

Requirement: separate semantic planning, visual identity, page layout, production automation, and publication instead of calling all of them “comic generators.”

### “Document every source and thought”

Requirement: maintain source quality, date, URL, observed fact, inference, caveat, and decision fields.

### “Use all research to build choTaku”

Requirement: convert research into schemas, validators, graph projections, layouts, provenance, MCP contracts, and fixtures.

### “Audit all AvatarArts Python”

Requirement: use Git tree inventory, classify capabilities, inspect representative source, detect duplicates, and separate archive code from authored product candidates.

### “Get on Trendshift and discover hot/rising opportunities”

Requirement: track velocity, cohort percentiles, multi-signal acceleration, external mentions, adoption, retention, and quality—not stars alone.

### “Automate content creation and distribution”

Requirement: one verified campaign brief must generate native drafts, source ledgers, launch assets, and analytics fields while preserving human approval.

### “Build future trends first”

Requirement: prioritize durable infrastructure—semantic state, provenance, skills, MCP, multimodal adapters, evals, memory, and packaging—before chasing individual platform trends.

It is:

> a provenance-aware creative ecosystem compiler that turns research, context, canon, identity, psychology, relationships, lore, scenes, layouts, and production constraints into reproducible multimodal artifacts and distribution packages.

Canonical flow:

```text
raw context
→ meaning
→ canon

→ panels, shots, pages, audio, video, and web projections
→ continuity and quality gates
→ provenance manifest
```

## 9. What to adapt versus what to reject

### Adapt

- editable story graphs
- tiered worldbuilding
- page and shot planning
- character image memory
- declarative layouts
- provider adapters
- portable skills
- narrow MCP contracts
- resumable state
- evaluation fixtures
- native package/distribution surfaces

### Reject or constrain

- prompt-only generation without canon
- silent mutation of originals
- vendor-specific semantic authority
- unbounded agent swarms
- unlicensed upstream incorporation
- trend chasing without adoption evidence
- fake engagement
- public claims unsupported by sources
- giant archives presented as finished products
- automation that publishes without approval
